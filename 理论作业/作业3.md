（2）进程地址空间与页大小 
进程地址空间：$2^{32}$ 字节 = 4 GB
页大小：页内偏移为12位，即 $2^{12}$ 字节 = 4 KB

（3）二级页表占用空间与连续性 
最多占用物理页框：一级页表有 $2^{10} = 1024$ 个页目录项，每个项对应一个二级页表，故最多占用 1024 个物理页框 。
连续性：不需要连续。二级页表通过一级页表项中的物理页框号进行寻址，可以离散分布在内存中 。

（4）页表空间映射分析 
第一级页表起始逻辑地址：虚拟地址 `0x77800000` 对应的页目录索引为 `0x77800000 >> 22 = 0x1de`
每个页表大小4KB，所以页目录对于页表虚拟地址起始位置的地址偏移为 `0x1de <<12 = 0x1de000`
起始逻辑地址为：`0x77800000 + 0x1de000 = 0x779de000`
第一级页表的物理地址（即页目录基地址）存储在页目录中指向它自身的那个表项里。
在该自映射方案中，页目录的第 478 个表项指向了页目录自己的物理地址。
该表项在虚拟地址空间中的位置，就是页目录起始地址加上该项的偏移：
`0x779de000 + (0x1de x 4) = 0x779de000 + 0x778 = 0x779de778`

（5）逻辑地址转换过程描述
1. 逻辑地址：`0x0`
地址拆分: PDI = 0, PTI = 0, Offset = 0。
一级访问: 查找页目录（基址 `0x1000`）第 0 项。图中页目录 Index 0 的内容为 `0x0`。
结论: 有效位为 0，发生缺页异常 (Page Fault)或非法访问。无法读取数据。

2. 逻辑地址：`0x00803004`
    地址拆分：`0000 0000 10 | 00 0000 0011 | 0000 0000 0100`
    PDI = `0x2` (2)
    PTI = `0x3` (3)
    Offset = `0x004`
    转换过程：
    1. 一级访问: 页目录第 2 项内容为 `0x5001`。有效位为 1，二级页表物理基址为 `0x5000`。
    2. 二级访问: 在物理地址 `0x5000` 的页表中查找第 3 项。图中该项内容为 `0x20001`。有效位为 1，物理页框号 (PFN) 为 `0x20`。
    3. 最终物理地址: `0x20 << 12 + 0x004 = 0x20004`。

    读取数据: 物理地址 `0x20004` 对应“物理地址 `0x20000` 页表”中的第 1 项。图中该位置的值为 `0x326001`。

3. 逻辑地址：`0x00402001`
    地址拆分：`0000 0000 01 | 00 0000 0010 | 0000 0000 0001`
    PDI = `0x1` (1)
    PTI = `0x2` (2)
    Offset = `0x001`
    转换过程：
    1. 一级访问: 页目录第 1 项内容为 `0x1001`。这表明该进程使用了页表自映射，二级页表其实就是页目录本身（基址 `0x1000`）。
    2. 二级访问: 在物理地址 `0x1000` 的页表中查找第 2 项（Index 2）。内容为 `0x5001`。有效位为 1，物理页框号为 `0x5`。
    3.  最终物理地址: `0x5 << 12 + 0x001 = 0x5001`。

    读取数据: 物理地址 `0x5001` 位于“物理地址 `0x5000` 页表”的第 0 项内部。图中 Index 0 的内容为 `0x0`。
